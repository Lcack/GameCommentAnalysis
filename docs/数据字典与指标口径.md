# 数据字典与指标口径

## 数据来源与范围

外部字段按 [Valve 官方接口文档](https://partner.steamgames.com/doc/webapi/IUserReviewsService) 核对。App ID 对应 [影之刃零](https://store.steampowered.com/app/4115450/?l=schinese)、[黑神话：悟空](https://store.steampowered.com/app/2358720/?l=schinese)、[鬼武者 Way of the Sword](https://store.steampowered.com/app/2638890/?l=japanese)。

默认简体中文、全部推荐状态、全部购买来源、包含平台标记的偏题活动评论；保留原始数据，当前不自动删除“疑似刷评”。筛选依据创建时间，不是更新时间。日期窗口按北京时间左闭右开，接口传入的上界为 end_ts-1。

## 表和粒度

| 表 | 主键/粒度 | 用途 |
|---|---|---|
| games | appid | 三款目标游戏及中文名 |
| aspects | aspect | 六类方面字典 |
| datasets | id | 一次固定窗口与筛选条件的采集任务 |
| collection_jobs | dataset_id + appid | 每游戏分页游标、页数、完成状态与错误 |
| reviews | dataset_id + review_id | 同一数据集首次纳入的评论版本 |
| analysis_runs | id | 固定模型、提示词原文/哈希、设置与抽样种子 |
| extraction_results | run_id + review_id | 入选评论处理状态、响应路径、尝试次数与用量 |
| mentions | run_id + review_id + mention_index | 一条具体方面反馈；评论可对应多条 |
| sampling_strata | run_id + appid + block_index | 时长百分位块的容量、理想/实际配额与入选概率 |
| sample_members | run_id + review_id | 入选评论所属百分位块及随机处理顺序 |

## reviews 字段

| 项目字段 | 类型 | 来源/含义 |
|---|---|---|
| review_id | TEXT | recommendationid，按字符串存储避免大整数转换损失 |
| appid | INTEGER | 当前游戏 App ID |
| review_text | TEXT | review，保留原文，不自动改写 |
| content_hash | TEXT | 原文 UTF-8 SHA-256，用于追踪输入版本 |
| language | TEXT | language |
| timestamp_created | INTEGER | 首次发表 Unix 秒 |
| timestamp_updated | INTEGER | 最新修改 Unix 秒；源缺失时回填创建时间 |
| voted_up | INTEGER/NULL | 1推荐、0不推荐；未知不等于0 |
| playtime_minutes | INTEGER/NULL | author.playtime_at_review，发表时分钟数；0是有效值 |
| playtime_forever_minutes | INTEGER/NULL | author.playtime_forever，采集时累计分钟数，主分组不用它 |
| steam_purchase | INTEGER/NULL | Steam购买标记 |
| received_for_free | INTEGER/NULL | 玩家标记免费获得 |
| votes_up | INTEGER/NULL | 有帮助票数；当前不加权 |
| observed_at | TEXT | 本地获取该页的UTC ISO时间 |
| raw_path | TEXT | 对应原始响应相对路径；原始响应可能包含公开SteamID，不提交公开仓库 |

`reviews_enriched` 增加游戏名、北京时间创建日期和时长组。负时长与 NULL 均归入缺失组，其他分组为 [0,120)、[120,600)、[600,1800)、[1800,3600)、[3600,+∞) 分钟。

## 模型状态

- pending：入选，尚未处理。
- success：正常结束、合法结构、字段与证据校验通过；不代表语义已人工确认。
- failed：请求失败、返回结构错误、截断、空内容、证据校验不通过等。
- skipped：空文本或超过20,000字符；不静默截断。

合法 `{"mentions":[]}` 为 success；无响应、空白输出不能转换为空数组。

`attempts` 为各次分析命令中实际HTTP尝试次数累加，不等于成功调用数或计费数。`elapsed_seconds`、`usage_json`、`response_path` 保存最后一次处理的信息；历次收到的原始模型响应独立留档。网络超时且未收到响应时 usage 未知，不能用空对象解释为0费用。

## 指标

| 指标 | 分子 | 分母/解释 |
|---|---|---|
| 不推荐比例 | voted_up=0 的评论 | voted_up 已知的评论；基础统计来自采集数据 |
| 模型处理成功率 | success 评论 | 固定入选评论，包含pending/failed/skipped |
| 某方面提及率 | 提及该方面的去重评论 | 同run、同游戏、同时长组的success评论 |
| 某方面负面提及率 | 存在该方面negative反馈的去重评论 | 同上，不把mixed自动纳入negative |
| 任一负面反馈比例 | 至少一个negative反馈的去重评论 | 对应日期的success评论，与整体不推荐不是同一指标 |
| 负面共现数 | 同时提及两个方面negative反馈的去重评论 | 输出计数，不自动解释为两个问题相互导致 |
| 日期变化 | 当前含负面反馈比例减上一有样本日期的比例 | 单位百分点，不是相对增长率，也不保证间隔一天 |

新运行默认在每游戏内按时长降序分为五个近似等人数块，以50/25/15/7/3分配名额，再在块内无放回随机抽取。种子、筛选条件和配额固定在run设置与manifest中；旧运行保留原来的均匀抽样定义。可选uniform提供筛选母体内的均匀对照。

百分位母体先排除未知/负时长、空文本和超过20,000字符的文本，再应用最低时长和文本长度筛选。top_percent表示截取该母体最高时长的前百分之几，向上取整，再分五块；不是按最大时长等距切割。平局由sha256(seed:review_id)确定，块边界允许切分同一时长，不能当成真实进度分界。

target_count按实际能够抽取的总量计算整数目标名额；某块容量不足时封顶，并将余量按权重分给仍有容量的块。selected_count为实际抽取数。inclusion_probability为块内selected_count/pool_count；块为空时NULL，非空但未抽取时0。此字段只作审计，当前未自动进行总体加权估计。

游戏间与时长块间抽样比例可能不同，提及率均为未加权的样本内比例，不直接汇总为“总体玩家问题率”。顶部截取之外的评论没有覆盖，不能通过简单加权补回。对于partial数据集，以上仅是流程样本统计。

多标签、多态度允许同一评论重复出现于不同指标；各方面比例不能相加。当同一评论同一方面同时包含正面与负面条目时，可同时计入对应指标，但每个指标内按评论去重。

## 人工评估

单位为评论级 `aspect+polarity` 集合。每标签 TP/FP/FN、precision、recall、F1 与support输出到CSV；空分母为null。另列exact-set-match与未成功处理样本数量。未标注行不作为无标签行；开发集不用于最终测试。

具体机制解释、标签证据是否充分、对象名与进度是否正确，需要额外人工核查。测试集若用于反复优化提示词，就应重新留出独立测试样本。当前命令只提供CSV排除功能，不会自动证明不存在人工信息泄漏。

分类与置信度：来源字段属于客观事实，高；表结构与指标定义属于本项目设计，可核对代码，高；代表性、因果与游戏参数方面的边界属于逻辑推断，高。标签真实准确率未知。
